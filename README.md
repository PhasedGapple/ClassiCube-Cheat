# ClassiCube External Cheat
A cheat for ClassiCube made in C# and WinForms. It uses Cheat Engine to find the offsets of the game and then overrides them to give you an advantage. Educational purposes only, I do NOT encourage cheating and ClassiCube is open source so a external cheat isnt the optimal way of making cheats.

## Common questions

**Q: Why did you make this**
- A: Just to attempt to earn some coins at Hack Club Crescent

**Q: How does this work/How did you make this**
- A: I made this with C# and WinForms and then just overriden some memory locations in ClassiCube. I got the offsets in Cheat Engine.

**Q: Why are most features not working?**
- A: Try closing the ClassiCube Home window and only open the ingame window AND MAKE SURE YOU ARE IN ENHANCED MODE (select in ClassiCube -> Options -> Mode)
